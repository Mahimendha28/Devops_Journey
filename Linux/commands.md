# Linux Commands Practiced

## Navigation

```bash
pwd
ls
ls -la
cd
```

## Create Files & Directories

```bash
mkdir
touch
```

## Copy

```bash
cp
cp -r
```

## Move & Rename

```bash
mv
```

## Delete

```bash
rm
rm -r
```

## View Files

```bash
cat
head
tail
```

## Terminal

```bash
clear
history
```
